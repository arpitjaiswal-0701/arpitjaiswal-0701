### How I build

- **Rules first.** If a script can do the job, a script does it. The model drafts and reviews; it never holds the pen on the final bytes.
- **You see every write before it lands.** Anything that touches a system of record shows the exact change and waits for a yes. A bad day for the model is a declined prompt, not a corrupted record.
- **No invented facts.** A name, number or date appears only when the evidence does. Enforced in code where the tool allows, not in a prompt.
- **A fresh reviewer attacks anything outward-facing** before it ships, and the numbers from real logs decide what changes next.

Each tool is a Claude Code skill: a prompt, the scripts it calls, and a README that states its limits.
