## Hi, I'm Arpit 👋

Senior Account Executive by day; by night I build **deterministic, human-gated automation**
for the un-fun parts of enterprise sales & ops — mostly as [Claude Code](https://claude.com/claude-code)
skills. A few themes run through everything here:

- **Rules-first, not vibes.** If a plain script can express the task, it's a script — the LLM
  drafts and reviews, it doesn't hold the pen on the final bytes.
- **Human-gated writes.** Anything that touches a system of record shows you the exact change
  and waits for your yes. No unattended bots.
- **No fabrication.** Named specifics come from evidence or get omitted — enforced in code.
